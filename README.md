# Bank_Customer_Data_Analysis-DAE


## Requirements
- Windows 10/11
- Python 3.10 or newer (Python 3.13 is fine)
- Internet connection on the first run to install packages

## Run
1. Extract the ZIP into a normal folder (not inside the ZIP preview).
2. Double-click `run_windows.bat`.
3. Wait for dependencies to install.
4. Open the local URL shown in the terminal, usually http://localhost:8501.
5. Keep the terminal window open while using the app.

The launcher uses `python`, not the optional `py` launcher. It creates a local `.venv` and installs packages there.

## Features
- Upload CSV data
- Customer filters
- Summary statistics
- Missing-value and duplicate checks
- Optional cleaning and downloads
- Interactive Plotly visualizations
- Synthetic demo data

## Important
The included sample data is only for demonstration. It is synthetic and must not be reported as actual bank data or real research findings. Use only datasets you are authorized to access.
